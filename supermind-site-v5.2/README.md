## Brand usage — read before touching the mark
Supplied artwork only. Never retype, redraw, stretch, outline, rotate, recolour or screenshot it.
Minimum 160 px wide on screen. Clear space 0.5× mark height each side (1× preferred).
Four colorways only — Signal White (screen default), Crown Gold (ceremony), Mirror Silver (performance), Functional Black (documents).
